# ギャラリー画像のアップロード先

このフォルダに画像ファイルを追加すると、公式サイトの「3人のフォトギャラリー」に自動で表示されます。公開用には、露出を控えた画像や季節・記念日・ドレスなどのイベント画像だけを追加してください。特別ミッション用・非公開の画像は追加しないでください。

## 追加方法
1. GitHubでこの `gallery` フォルダを開きます。
2. **Add file → Upload files** を選びます。
3. PNG / JPG / JPEG / GIF / WEBP / AVIF の画像をまとめてドラッグ＆ドロップします。
4. **Commit changes** で保存します。

サイト側のHTMLを編集する必要はありません。反映にはGitHub Pagesの更新時間が少しかかる場合があります。画像のファイル名はサイト上のキャプションにも使われます。日本語のファイル名も使用できます。
