# 美月＆紬 Project 公式サイト

このリポジトリは「美月＆紬 Project」公式サイトの公開用正本です。

## 運用ルール
- 公開サイトの更新は、このリポジトリの `main` ブランチを正本として行います。
- `index.html` と `style.css` が現在のサイト本体です。
- ChatGPTの美月がサイトを更新するときも、このリポジトリを更新対象とします。
- 別コピーを新しい正本として扱わないでください。
